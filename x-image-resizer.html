How X (Twitter) Handles Images in Timelines

On the X web and mobile apps, single image posts display cleanly in a 16:9 ratio (1600 × 900 px). When photos deviate too far from standard ratios, X applies automated vertical cropping that can hide important context, charts, or punchlines.

X Image Type Recommended Dimensions Aspect Ratio Formatting Advice
Single Post Image 1600 × 900 px 16:9 Renders without cropping or clipping on both mobile and desktop feeds.
Header Banner 1500 × 500 px 3:1 Leave bottom-left clear for circular avatar; leave top/bottom margins for responsive scaling.
Profile Photo 400 × 400 px 1:1 High-res avatar cropped into a clean circle.
